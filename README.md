\# TrustLayer



AI-Based Digital Identity Verification and Anti-Impersonation System.



\## Features

\- Image authenticity analysis

\- Voice authenticity analysis

\- Text scam detection

\- Trust score-based verification



\## Technologies

\- Python

\- Flutter

\- PostgreSQL

\- Machine Learning



\## Project Structure

\- `backend/` – Backend application

\- `frontend/` – Flutter application

\- `models\_weights/` – Machine learning model files
